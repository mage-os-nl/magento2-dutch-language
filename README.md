# mage-os-nl/magento2-dutch-language

**Dutch language pack for Magento 2**

## Installation
```bash
composer require mage-os-nl/magento2-dutch-language
```

## Configuration
This language pack requires no configuration, except that the Dutch locale is configured - for either your
storefront, your backend account or both:

- **Account > Settings > Account information > Interface Locale**
- **Stores > Settings > Configuration > [storeview] > Locale options > Locale**
